# 🏢 시총 키우기 (Stock Merge)

주식 테마 머지 게임 — 작은 씨드 투자부터 삼성전자까지 시총을 키워보세요!

## 🎮 게임 방법

1. **자동으로 좌우 이동**하는 공을 타이밍에 맞춰 **탭**하여 드롭
2. **같은 등급**의 공이 만나면 **합체**하여 다음 등급으로 성장
3. 연속 합체 시 **콤보 보너스** 획득
4. 공이 경고선을 넘으면 **게임 오버**
5. 3초 안에 드롭하지 않으면 공이 **점점 커지는** 패널티!

## 📈 성장 단계

|------|------|------|

| 10 | 삼성전자 | 10조 |
